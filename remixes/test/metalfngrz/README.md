# METALFNGRZ (test)

8thmyth's firmware: `octabam-lazy-chop` as it is, plus LAZY CHOP TEMPO and Hteah's TRACK TRIG MODE, PAGE LOOP and TRIG MUTE (github.com/Hteah/ot-mods, MIT). PATTERN MUTE is left out: it shares the one-shot mask's byte. The image calls itself `METALFNGRZ <BUILD>`; with `BUILD=TA` the REMIX SWITCH file is `METALFNGRZ TA.RMX`. Gates: `verify_lazy_chop.py`, `verify_lock_edit.py`, `verify_zoom_keep.py`, `verify_src3_key.py`, `verify_chop_tempo.py`, `verify_track_trig_mode.py`, `verify_page_loop.py`, `verify_trig_mute.py`, each with `metalfngrz`.
